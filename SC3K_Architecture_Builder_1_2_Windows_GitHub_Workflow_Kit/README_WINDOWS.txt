SC3K Architecture Builder is an isometric pixel-art architecture editor
with a facade module editor, a facade assembly editor, and a building
volume editor. It supports ISO/FRONT sprite assets, roof colours,
procedural roof stripes, cast shadows, and 15-degree rotations.

RUNNING THE WINDOWS APPLICATION
-------------------------------
1. Extract the whole downloaded artifact ZIP to a folder on Windows.
2. Launch "SC3K Architecture Builder.exe".
3. Keep the accompanying _internal directory together with the EXE.
   Do NOT move the EXE out of its folder: it needs bundled resources.
4. If Windows SmartScreen displays an unrecognised publisher warning,
   note that this is an unsigned build. Run only if you trust the source.

FACADE PROJECTS AND FILES
-------------------------
Use the Save Project JSON / Open Project JSON buttons in the second tab
to save or reopen facade assemblies. The Volume tab also exports PNG
and JSON. By default, facade exports can be saved to:
Documents\SC3K Architecture Builder\Exports

The internal sprite library and both colour palettes are bundled with
the application. They do not need to be downloaded separately.
